📋 流水线说明

Alpha 流水线是一套全自动化的量化策略执行工作流，由5个专业Agent按顺序协作完成。点击「运行完整流水线」即可一键执行全部环节，也可以单独运行某个Agent。

📊 DataAgent · 数据管家
判断交易日、同步全市场行情、数据质量检查
🔍 SignalAgent · 信号猎手
运行5策略融合扫描 + v4超跌反弹策略，生成候选股票
📈 BacktestAgent · 回测验证
对候选股做历史回测，计算胜率、盈亏比、最大回撤
🛡️ RiskAgent · 风控官
大盘风险评估、个股风险筛查、仓位建议、系统化风控
📝 ReportAgent · 报告生成
整合所有Agent输出，生成HTML交易计划报告
