### 6. 修复 Bat 脚本执行问题
- **问题**: `start.bat` 双击后一闪而过，窗口关闭
- **根因**: `chcp 65001 >nul` UTF-8 代码页设置和 `2>&1` 重定向在部分 Windows CMD 环境中兼容性问题，导致命令解析错误（`'evel' 不是内部或外部命令`）
- **修复**: 重写所有 Bat 脚本，采用保守语法：
  - 移除 `chcp 65001`，使用系统默认代码页
  - 移除 `2>&1`，仅用 `>nul` 重定向
  - `if errorlevel 1` 替换为 `if %errorlevel% neq 0`
  - 添加 `setlocal EnableDelayedExpansion`
  - 简化中文字符，减少编码风险
