# 2026-05-13 工作记录

## 流水线日志透传：前端实时显示 Agent 进度

### 问题
前端流水线执行日志面板只显示 orchestrator 层面的"启动/完成"日志，看不到 DataAgent 拉数据进度和 SignalAgent 扫描进度。Agent 内部的 `print` 只输出到 Python stdout，未被捕获到 API 响应中。

### 方案
1. `scheduler/state.py`: `PIPELINE_STATUS` 增加 `logs` 列表；新增 `append_log()`（线程安全）和 `get_logs(since)` 增量获取函数；限制最多保留500条。
2. `agents/base.py`: `AgentContext` 新增 `log(level, message)` 方法，自动读取 `_current_agent` 并调用 `append_log`；`BaseAgent.run` 执行前将 `self.name` 写入 `_current_agent`。
3. `agents/orchestrator.py`: `run_pipeline` 启动时清空旧日志；各阶段标题、Agent 启动/完成/异常 等关键节点同步调用 `append_log`。
4. `agents/data_agent.py`: `_run_sync` 中的同步进度 `print` 改为同时调用 `ctx.log("info", ...)`。
5. `agents/signal_agent.py`: 扫描进度 `print` 改为同时调用 `ctx.log("info", ...)`。
6. `routes/agents.py`: `/api/agents/status` 支持 `?since=N` 参数，返回增量日志 `logs` 和 `log_total`。
7. `dashboard.html`:
   - 新增全局变量 `lastLogIndex`
   - 新增 `addPipelineLogRaw(timeStr, type, message)` 和 `appendBackendLogs(logs, logTotal)`
   - `runPipeline()` 重置 `lastLogIndex = 0` 并清空面板
   - `refreshPipelineStatus()` 和 `startPolling()` 请求 `/api/agents/status?since=${lastLogIndex}`，追加新日志到面板

### 验证
- 所有修改模块语法检查通过（state/base/orchestrator/data_agent/signal_agent/routes）。

## 修复 DataAgent NameError: name 'ctx' is not defined

### 问题
`agents/data_agent.py` 的 `_run_sync` 方法签名只有 `(self, today, full)`，但方法内部直接使用了 `ctx.log(...)` 和 `ctx.log(...)` —— `ctx` 根本没有作为参数传进来，导致 `NameError`。

### 修复
- `_run_sync` 签名改为 `(self, today: str, full: bool, ctx: AgentContext = None)`  
- 内部所有 `ctx.log(...)` 调用包裹 `if ctx:` 防空  
- 调用处 `self._run_sync(today, full=is_after_close)` → `self._run_sync(today, full=is_after_close, ctx=ctx)`
