# 龙虎榜「机构专用席位」建仓跟踪（stock_lhb_jg_detail）

> 改这条链路前**必读 §2 口径陷阱**——它是本模块唯一会让数据悄悄错掉的地方。
> 一句话结论：**机构买卖方向对次日收益无区分度，不要当买点用**；有价值的是「成本位」。

## 2. ⚠ 口径陷阱：同一 (date, code) 并存多行，金额随 reason 变窗口

**这是本模块最容易踩的坑，实测数据（`tools/_probe_lhb_jg.py` / `_probe_lhb_jg2.py`）：**

同一股票同一天会因**不同上榜原因**各占一行（实测 484 个重复组，其中 **294 组数值不一致**）。
原因是「市场总成交额 / 机构买卖额」按 reason 的统计窗口计算：

| 上榜原因 | 接口成交额 ÷ `daily_price.amount` | 口径 |
|---|---|---|
| 「日涨幅偏离值达到7%」「日换手率达到20%」「日振幅值达到15%」等 | **1.00x** | **单日** |
| 「连续三个交易日内…」 | 2.0 ~ 2.3x | 3 日累计 |
| 「连续三个交易日内，跌幅偏离值累计达到20%」 | 3.4 ~ 4.8x | 3 日累计 |
| 「连续10个交易日内…累计100%」 | 10 日累计 | |

**而 `close_price` / `pct_change` / `turnover_rate` / `float_mkt_cap` 在两种口径下完全一致**（恒为当日值）。

推论（改代码前必须遵守）：

1. **主键含 reason**：`UNIQUE(trade_date, code, reason)`，**绝不按 (trade_date, code) 聚合**——对比 `fetch_lhb_detail()` 的做法（它按票聚合，`stock_lhb_detail` 因此也混了 3 日累计额，是历史遗留问题，未修）。
2. 金额字段**不可跨 reason 相加**。
3. 要「当日机构动向」→ 筛 `window_days = 1`（由 `_jg_window_days()` 从 reason 解析）。
4. 本模块的价格一律取 **`daily_price` 前复权价**，不用接口自带的 `close_price`（原始价，混价源会出错）。

## 3. 🚫 诊断结论：机构买卖方向无效

窗口 2024-07-01 ~ 2026-09-22，13350 条样本（6173 净买 / 7177 净卖）。
口径：T 日盘后公布 ⇒ **T+1 开盘买入**（时点正确）；价格取 `daily_price` 前复权。

### 3.1 机构净买 vs 机构净卖：全部不显著

| 持有 | A 机构净买>0 | B 机构净卖≤0 | Δ | t |
|---|---|---|---|---|
| 1 日 | +0.72%（49.5%） | +0.66%（48.9%） | +0.058pp | +0.53 |
| 5 日 | −0.73%（41.1%） | −0.86%（39.4%） | +0.129pp | +0.53 |
| 10 日 | −1.06%（38.1%） | −1.49%（36.4%） | +0.425pp | +1.29 |

### 3.2 决定性对照：同「近 20 日机构榜出现 ≥K 次」下，净卖方反而更好

**若收益来自机构方向，「净买」应显著优于「净卖」。实测是反的：**

| 近 20 日机构榜出现 | 当日机构净买 | 当日机构净卖 | 方向差 |
|---|---|---|---|
| ≥ 3 次 | +0.89%（50.0%） | **+1.15%（51.5%）** | Δ=−0.265pp t=−1.40 |
| ≥ 4 次 | +0.94%（50.3%） | **+1.19%（51.4%）** | Δ=−0.252pp t=−1.14 |
| ≥ 5 次 | +1.09%（51.7%） | +1.14%（51.1%） | Δ=−0.050pp t=−0.20 |

⇒ **收益来自「频繁上榜（活跃度）」，与机构方向无关。** 这是本次最重要的结论。

### 3.3 「近 20 日机构净买 ≥ 4 次」看似显著，但过不了铁律 3

`+1.22% / 胜率 53.0%`，vs 全子集 Δ=+0.499pp **t=+2.24 ✓**（首轮最亮眼的一条）。

但：

- **Δ 不单调**：≥2 次 +0.223 / ≥3 次 +0.229 / ≥4 次 +0.499 / ≥5 次 +0.191 / ≥6 次 −0.109 / ≥7 次 +0.521 —— 典型的挑参数形态。
- **剔除单年即不显著**：剔除 2025 → t=+1.60；剔除 2026 → t=+1.38。
- 5 日持有反而 −1.08%（持有越久越差）。

⇒ **不采纳。**

### 3.4 其它分档（均取自「机构净买>0」子集，持有 1 日）

| 变量 | 分档表现 | 判定 |
|---|---|---|
| 净买额 / 流通市值 | 0~0.5% +0.66% / 1.5~3% +1.02% / 3%+ **+0.29%** | 非单调 |
| 净买额占成交额 | 0~1% **+1.06%** / 8%+ +0.36% | **反向**（比例越小越好） |
| 买方机构家数 | 1 家 **+0.89%** / 3~6 家 +0.62% | **反向** |
| 上榜日涨幅 | 3~7% **+1.37%** / ≥9.8%（涨停）+0.26% | 涨停票差（与已知「涨停次日溢价被吃」一致） |

### 3.5 待深挖的新线索（未采纳，仅记录）

「频繁上榜」本身是真实效应：近 20 日机构榜出现 ≥3/4 次 → 1 日 +0.89%/+1.15%~+1.19%，
**分年（2024/2025/2026）三年均为正**。但注意该收益含 T+1 开盘相对 T 收盘的跳空成分，
且未做「剔除单年」检验，也未经组合口径（每日 top-N）验证 ⇒ **不可直接使用**，铁律 7。

## 4. API 与前端

`GET /api/investor/lhb_jg_track`

| 参数 | 默认 | 说明 |
|---|---|---|
| `days` | 20 | 回看交易日（5~120） |
| `min_cnt` | 2 | 最少机构净买次数 |
| `limit` | 30 | 返回上限（1~100） |
| `sort` | `cum_ratio` | `cum_ratio` 建仓力度 / `vs_cost` 现价低于成本优先 |
| `only_priced` | 1 | 只留有行情的票（科创板 688 / 北交所 920 无本地行情） |

返回字段核心：

- `cost_est` = **Σ(机构净买额 × 当日收盘价) / Σ(机构净买额)**，只对净买为正的上榜日加权
  ⇒ **机构建仓成本估算**（接口不披露机构真实成交价，这是可得的最优近似，前端须标「估算值」）
- `band_low/band_high` = 各上榜日 [最低, 最高] 极值（前复权）
- `vs_cost` = 现价相对成本（%），`cum_ratio` = 累计净买额 / 流通市值（%）
- `skipped_no_price` = 因无本地行情被剔除的只数

**前端定位（不可改成「推荐」口吻）**：栏目文案明确写「资金动向与成本位参考，**不是收益信号**」，
并附实测数字。`现价低于机构成本 = 机构被套`，属**风险提示**。

实测前端 60 日窗口：命中 40 只中 15 只高于成本 / 25 只低于成本；
无行情剔除约 25%（全部为 920 北交所 + 688 科创板）。
