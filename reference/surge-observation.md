# 次日强势观察（强势突破）· 成绩单归因与修复提案

> 触发：2026-09-20 用户反馈「模块看起来不太行，胜率没超过 45%，收益是负的」。
> 结论：**不是信号崩了，是「考核口径 + 小样本 + 门控转向」三件事叠加出来的读数**。
> 诊断脚本：`tools/_diag_surge_perf.py`（单条明细）、`tools/_diag_surge_replay.py`（历史重放）。
> 重放窗口 **2024-07-01 ~ 2026-09-15，539 个交易日**（龙虎榜数据起点 2024-07-01）。

## 2. 根因一：出场周期与信号半衰期错配（**主因**）

T+n 相对「次日开盘买入价」的收盘收益（主板，n=1306）：

| | T+1 | T+2 | T+3 | T+4 | T+5 |
|---|---|---|---|---|---|
| 均值 | **+0.06%** | -0.11% | -0.07% | -0.19% | **-0.32%** |
| 胜率 | 45.5% | 43.1% | 42.8% | 41.0% | 40.7% |

**信号只有 T+1 一天的有效性，T+2 起是负漂移**。而 `SURGE_BREAKOUT["max_hold_days"]=5`
让成绩单把 T+1 的浮盈原路还回去。实盘窗更极端：

| 口径（同一批 n=90） | 胜率 | 均值 |
|---|---|---|
| OC 次日收盘了结 | 47.8% | **+0.16%** |
| A 现网 5 日持有 | 26.7% | **-2.11%** |
| C 盘中触价（跳空按更差价成交） | 27.8% | -1.32% |

现网 A 口径出场分布（n=1306）：止损 651（50%）/ 到期 404（31%）/ 止盈 230（18%）。
`+8% 止盈用收盘判定` → 只有 18% 能触发；止损 50% 触发，且跳空穿透把 -4% 放大到最差 -19.21%。

⚠ 反例：龙虎榜子集的右尾在 **T+4/T+5** 才兑现（+0.67% / +1.17%），与全族相反。
n=65 太薄，不作为决策依据，仅记录。

## 3. 根因二：样本量不可读

龙虎榜硬过滤把 1306 条砍到 65 条（**-95%**），60 天窗口只剩 7 条。
n=7 时一笔交易 = 14.3pp 的胜率台阶 —— 33.3% 与 45% 的差就是一笔。
截图上的 28.6% 因此**没有统计意义**，不能据此判定信号失效。

## 4. 根因三：大盘门控在 2026 年方向反转

`max_market_pct = 1.0`（当日全市场平均涨幅 ≥1% 不出信号）：

| 窗口 | 放行日候选 | 被拦截（火热日） | 拦截 − 放行 |
|---|---|---|---|
| 2024-07 ~ 2026-01（训练窗） | n=792, +0.07% | n=194, -3.27% | **-3.34pp, t=-9.39 ✓** |
| 2026-01-25 ~ 2026-09（验证窗） | n=514, +0.04% | n=127, **+1.02%** | **+0.98pp, t=+2.50 ✗ 反向** |
| 全期 | n=1306, +0.06% | n=321, -1.58% | -1.63pp, t=-5.65 ✓ |

训练窗门控完全正确，验证窗（含实盘段）**显著反向**。全期仍正确 ⇒ 不删，加复审标记。

## 5. 龙虎榜硬过滤的真实作用（被误判的一环）

| 窗口 | 未上榜 | 上榜净买>0 | 差值 / t |
|---|---|---|---|
| 训练窗 2024-07~2026-01 | n=792, +0.07% | n=31, +1.27% | +1.21pp, t=+1.10 |
| 验证窗 2026-01-25~ | n=514, +0.04% | n=34, **-0.62%** | **-0.66pp, t=-0.77** |
| 全期 | n=1306, +0.06% | n=65, +0.28% | +0.23pp, t=+0.33 |

**跨窗不稳定、全部不显著**（违反铁律 3「分年 + 剔除单年都要成立」）。
但它确实兑现了栏目承诺的**右尾**：触涨停率 6.6% → 21.5%（3.3x）、大涨率 10.9% → 16.9%。
⇒ **它的作用是提高右尾命中率，不是提高期望收益**。不该删，该把考核指标换掉。

## 9. 2026-09-22 落地：出场改「隔日了结」

用户反馈「收益不高、胜率也不高」触发出场口径调优。
调优脚本 `tools/_diag_surge_tune.py`（主板 544 交易日，2024-07-01~2026-09-22，全族 1823 条候选）。

### 9.1 先纠正一个错误结论：旧 C 口径有前视偏差

`tools/_diag_surge_perf.py` 的 **C 口径（盘中触价）跳过 T+1 的出场判定**，
于是「开盘已跌破止损线」的票在几天后反弹回止损线时按止损价成交。
实例 603221 爱丽家居：信号日 33.37 → 次日开盘 30.03（破位）→ C 口径记 **+6.69%**，
现实是买入即亏。**C 口径的 +1.99% 均值不可采信**，不要引用它。

### 9.2 全族实测（n=1695，同一批样本，唯一变量 = 出场规则）

| 口径 | 胜率 | 均值 | 最差 |
|---|---|---|---|
| 基线·现网（5日/收盘/不判建仓日） | 36.9% | -0.19% | **-26.28%** |
| 5日 + 建仓当日判定 | 36.3% | -0.17% | -15.24% |
| 5日 + 日内触价 | 31.1% | -0.06% | -9.08% |
| **隔日了结（T+1 收盘 / 判建仓当日 / 开盘破止损不入场）** | **45.6%** | **+0.09%** | -12.47% |
| 隔日了结 + 日内触价 | 40.5% | +0.07% | -8.60% |
| 隔日 + 日内 + 弃高开≥3% | 40.4% | +0.10% | -6.78% |
| 隔日 + 日内 + 止盈5% | 42.1% | +0.00% | -8.32% |

分年（**候选：隔日了结**）：2024 `40.8%/-0.20%` · 2025 `45.1%/+0.04%` · 2026 `47.1%/+0.19%`
分年（基线）：2024 `36.6%/+0.20%` · 2025 `36.8%/-0.20%` · 2026 `37.0%/-0.28%`
⇒ **胜率改善分年单调且方向一致（+4.2 / +8.3 / +10.1pp）**，这正是铁律 3 要的形态。
均值 Δ=+0.277pp（t=+1.36，不显著）⇒ 收益提升是「把负期望拉回零附近」，不是造 alpha。

### 9.3 落地改动

| 文件 | 改动 |
|---|---|
| `config/strategy_params.py` | `max_hold_days` 5 → **1**；新增 `judge_entry_day=True` |
| `routes/investor.py::_surge_history` | 建仓当日纳入判定；新增「**开盘破止损 → 放弃**」（跳空破位不买入）；T+1~T+5 改为**持有漂移对照**（与出场规则解耦，便于观察拿更久是否更好） |
| `dashboard.html` | 口径文案改「隔日了结」；**样本 <30 条时显式警示统计不可读**；T+1 卡高亮为实际出场口径 |
| `tests/_verify_surge_history.py` | 独立复算同步新口径 + 新增放弃标签/持仓上限断言（**72 PASS**） |

回滚：`max_hold_days` 置 5、`judge_entry_day` 置 False 即恢复旧口径（T+n 漂移对照不受影响）。

### 9.4 试过但不采纳（留档，避免以后重复推）

| 候选 | 全族胜率 / 均值 | 不采纳原因 |
|---|---|---|
| 弃高开 ≥+3% | 46.0% / +0.13% | 增益在噪声内（+0.04pp）；线上 LHB 子集胜率反降（46.6%→45.3%） |
| 日内触价（含建仓当日） | 40.5% / +0.07% | 胜率低 5.1pp（盘中假突破扫损） |
| 止盈降到 +5% | 42.1% / +0.00% | 收盘判定下止盈阈值只改「标签」不改收益（0/9 触发过） |
| 止损收紧到 -3% | 37.4% / -0.11% | 双向都变差 |
| 信号日涨幅上限 9.8%→9.0% | 9~9.8 档**反而** +0.65% | 分档非单调（5~6 -0.07 / 6~7 +0.31 / 7~8 -0.12 / 8~9 +0.16 / 9~9.8 +0.65），无依据 |

入场分档（候选3 口径，信号日涨幅）：**非单调，不要按涨幅设上限**。
入场分档（次日跳空）：≤-4% 全部放弃(114) / -4~-2 `49.8%/+0.34%` / -2~0 `45.7%/-0.06%` /
0~+2 `44.0%/+0.23%` / +2~+3 `50.8%/+0.71%` / **+3~∞ `32.7%/-1.16%`**（最差档，n=49）。

### 9.5 线上实况（180 天窗，8 条）

| | 原口径 | 新口径 |
|---|---|---|
| 结算胜率 | 25.0% | **33.3%** |
| 结算平均 | -2.54% | -2.86% |
| 触发止损 | 6 | 3 |
| 最差 | -8.16% | **-6.55%** |
| 持仓天数 | 1~5 | 全 1 |

2 条（603221 爱丽家居、600613 神奇制药）因次日 **-10% 一字板开盘破止损**被放弃（原先记 0.00%，掩盖了「根本不会买」）。

⚠ **这批样本入场质量差**（4/6 低开），且 **n=6 不可读**（一笔 = ±16.7pp 台阶）。
出场规则修复的是**长期分布**（n=1695 胜率 +8.7pp），不是这一小批的读数。

### 9.6 仍未解决（下一阶段）

**入场端的系统性问题**：龙虎榜净买 + 大阳突破的候选，次日集体低开 —— 疑似游资一日游次日砸盘。
现有过滤链（门控 / LHB 硬过滤 / 市值 / 流动性）都已测过且不显著（§4 §5），
提胜率要靠**入场择时**（新变量），不是继续调出场参数。候选方向：
连续上榜天数、净买额/流通市值比、信号日是否留下长上影、板块联动强度（需行业数据源）。
