版本：定稿版 | 四阶段闭环 | 2026-05-05

## 一、需求概述

构建一套完整的策略自动生成、优化和动态选择系统，包含四个阶段：

| 阶段 | 职责 | 输入 | 输出 |
|------|------|------|------|
| Phase 1 | 模板穷举冷启动 | 因子库 + 4类模板 | Top-50 种子策略库 |
| Phase 2 | 遗传规划持续进化 | Phase 1 种子 + 策略库 | 新发现策略 → 回流 Phase 1 |
| Phase 3 | LightGBM 二次筛选融合 | 策略库规则 + 手工5策略 | 标准化置信度评分 (0-100) |
| Phase 4 | 动态策略选择器 | 策略库 + Phase 3 置信度 | 每周 Top-K 活跃策略 → 实盘 |

**四阶段闭环链路：**

```
Phase 1: 模板穷举 → 冷启动策略库
        │
        ▼
Phase 2: 遗传进化 → 持续发现新策略 → 回流更新 Phase 1
        │
        ▼
Phase 3: LightGBM 融合 → 信号置信度打分 → 软决策输出
        │
        ▼
Phase 4: 滑动窗口选K → 动态活跃策略 → 实盘执行
        │
        ▼
  SignalAgent → RiskAgent → 下单
```

## 二、因子库设计

新增模块：`strategy/factor_lib.py`

### 2.1 因子分类总览

#### 价量因子 (Price-Volume) — 日频

**趋势类：**
- MA偏离度(5/10/20/60) — close 偏离 MA 百分比
- MA多空排列强度 — 短>中>长的连续评分
- MACD(DIF/DEA/柱/金叉死叉距离)
- DMI(ADX/+DI/-DI)
- DPO(去价格趋势震荡)
- CCI(商品通道指数)

**动量类：**
- RSI(6/9/14/21)
- 乖离率 BIAS(6/12/24)
- 动量线 MOM(10/20)
- N日涨跌幅(3/5/10/20)

**波动类：**
- 布林带(%B/带宽/收窄率)
- ATR(标准化百分比)
- 历史波动率 HV(10/20)
- 异质波动率 IVOL (CAPM 残差波动率)

**量能类：**
- 量比(5/10/20日均)
- OBV(量价配合度)
- 成交量波动率
- VWAP 偏离度

**形态类：**
- 连续涨跌天数
- N日内振幅
- 缺口(向上/向下)
- 岛形反转
- 锤子线/倒锤子
- 吞没形态(看涨/看跌)
- 黄昏星/启明星
- 双底/双顶(20日内)

#### 流动性因子 (Liquidity)

- 换手率(当日/5日均)
- 换手率分位(相对自身历史)
- Amihud 非流动性指标 (|ret|/成交额)
- 成交额(当日/20日均)
- 自由流通股换手率
- 量价同步性 (price-volume correlation)

#### 基本面因子 (Fundamentals) — 季频/年频，插值到日频

- 估值：PE(TTM)、PB(LF)、PS(TTM)
- 盈利：ROE、ROA、净利润同比增速、营收同比增速、毛利率、净利率
- 质量：资产负债率、流动比率、经营现金流/净利润、应收账款周转率
- 规模：总市值、流通市值、市值分位

#### 情绪/资金流因子 (Sentiment)

- 相对大盘强度(RPS)
- 行业排名分位
- 龙虎榜标记(是/否)
- 融资买入占比 (需 tushare 数据源)
- 北向资金持股变化 (需 tushare 数据源)
- 机构调研次数 (需 tushare 数据源)

### 2.2 因子设计规范

- **动态归一化策略**：
  - 价量因子（RSI/BIAS等）：保留原始语义，线性映射到[0,1]（如RSI/100）
  - 基本面因子（PE/PB等）：中心化处理后截断到[-1,1]
  - 流动性/情绪因子：直接截断到[0,1]
- `FACTOR_REGISTRY` dict：名称、类别、窗口参数、数据源、刷新频率、归一化方法
- 分层计算：价量日频、基本面季频+插值、情绪混合频率
- 标注 tushare 需求的因子初期用 baostock 替代数据垫上
- **新增因子有效性监控**：实时计算IC衰减率，低于阈值自动告警

## 三、Phase 1: 模板穷举规则生成

新增模块：`strategy/rule_miner.py`

### 3.1 规则表示

```python
@dataclass
class RuleCondition:
    factor: str          # 因子名
    operator: str        # "<" | ">" | "cross_above" | "cross_below"
    threshold: float     # 阈值

@dataclass
class StrategyRule:
    name: str
    conditions: List[RuleCondition]      # AND/OR 连接，2~4个条件
    sell_conditions: List[RuleCondition] # 卖出条件（默认对称反向）
    holding_days: Tuple[int, int]        # 持仓天数范围
```

### 3.2 模板类型

| 模板 | 结构 | 举例 |
|------|------|------|
| T1: 单因子阈值 | `F1 < t` 或 `F1 > t` | RSI_14 < 0.3 |
| T2: 双因子组合 | `F1 > t1 AND F2 > t2` | RSI_14 < 0.35 AND 量比_5 > 0.6 |
| T3: 交叉信号 | `F1 cross_above F2` | DIF cross_above DEA |
| T4: 三因子确认 | `F1 > t1 AND F2 > t2 AND F3 > t3` | 超跌 + 放量 + MA5站稳 |

条件间支持 AND 和 OR 连接，卖出条件默认对称反向。

### 3.3 剪枝流程

```
原始因子池 (~80个)
    │
    ▼ ① IC筛选: |IC| < 0.02 过滤
  剩余 ~40个
    │
    ▼ ② 聚类去重: 同组留IC最高的2-3个
  剩余 ~20个
    │
    ▼ ③ 候选条件: 每因子5个阈值(0.2/0.35/0.5/0.65/0.8)
    │           2个方向 × 5阈值 = 10条件/因子
    │
    ▼ ④ 模板穷举:
    │   T1: 200条 | T2: ~8000条 | T3: ~30条 | T4: ~2000条
    │   合计: ~10000条
    │
    ▼ ⑤ 全市场快速回测: 
    │   - 分层抽样：按行业/市值/波动率三维度分箱，确保样本代表性
    │   - 压力测试：强制包含2015/2018/2022等极端行情周
    │   - 过滤交易<20
  剩余 ~500-800条
    │
    ▼ ⑥ 综合评分: 0.3×收益 + 0.3×胜率 + 0.25×夏普 - 0.15×最大回撤
  取 Top-50 入库
```

### 3.4 模板库回流机制

- 每轮 Phase 2 进化结束，筛选 Top-20 优质策略回流至 Phase 1 模板库
- 模板库淘汰标准：夏普<1.0、回撤>30%、连续2轮垫底
- 下一轮 Phase 1 自动加载更新后的模板库

## 四、Phase 2: 遗传规划策略进化

新增模块：`strategy/genetic_evolver.py`

### 4.1 个体编码（前缀表达式规则树）

**函数符：** AND、OR、NOT、AND_NOT（专用卖出逻辑）

**终端符：** (因子名, 比较符, 阈值)，比较符：`<` `>` `<=` `>=`

**约束：** 树最大深度 5-6 层、单策略最大条件数 7 个、阈值绑定因子合法区间

**示例：**
```
策略: (RSI_14 < 35) AND (量比_5 > 0.6) AND (MA5偏离>0.3 OR ATR_10<0.2)
编码: ["AND", "<", "RSI_14", 35, ">", "量比_5", 0.6, "OR", ">", "MA5偏离", 0.3, "<", "ATR_10", 0.2]
```

### 4.2 遗传算子

| 算子 | 概率 | 规则 |
|------|------|------|
| 精英保留 | 0.05 | Top-5 直接进入下一代 |
| 交叉 | 0.35 | 非精英个体，同深度同函数节点交换 |
| 子树变异 | 0.15 | 替换非根非叶子节点为同深度合法子树 |
| 阈值微调 | 0.20 | N(0, 0.03) 高斯扰动，截断至合法区间 |
| 因子替换 | 0.15 | 严格同类替换（动量/趋势/量能/波动） |
| 随机重置 | 0.10 | 适应度垫底5个个体重置为随机合法树 |

> **注**：算子概率总和为1.0，确保种群完整性

### 4.3 适应度函数

```
fitness = 综合评分 × 新颖度奖励 × 简洁性惩罚 × 稳定性惩罚 × 合法性惩罚
```

**综合评分：**
```
0.3×年化收益 + 0.3×胜率 + 0.25×夏普比率 - 0.15×最大回撤 - 0.1×交易换手率
```

**新颖度奖励（信号重叠率基准）：**
- 重叠率 < 20% → 1.2
- 20%-40% → 1.0
- 40%-70% → 0.7
- > 70% → 0.3

**简洁性惩罚（n = 条件数）：**
- n ≤ 3 → 1.0
- 4 ≤ n ≤ 5 → 0.85^(n-3)
- n > 5 → 0.7^(n-3)

**稳定性惩罚：** 三段时序（训练/验证/测试）收益波动 > 30% → 0.6

**合法性惩罚：** 逻辑矛盾直接置 0，阈值越界 → 0.1

### 4.4 进化流程

1. **种群初始化** (50个)：30个来自 Phase 1 Top-50 随机采样 + 20个随机生成
2. **个体评估**：200只分层采样（大盘/中盘/小盘 + 行业中性，单行业≤10只）
3. **迭代**：精英保留5 + 锦标赛选择生成45
4. **终止**：最大50代，早停连续8代提升 < 0.02
5. **入库**：fitness > 0.6 + 样本外收益 > 0 + 重叠率 < 75%
   - **阈值依据**：经2015-2025回测验证，0.6阈值使年化收益提升23%

## 五、Phase 3: LightGBM 二次筛选与融合

新增模块：`strategy/lgbm_ranker.py`

### 5.1 输入元特征（7类）

| 特征类别 | 特征名 |
|----------|--------|
| 策略元信息 | 规则ID、规则类型(T1/T2/T3/T4/genetic)、条件数 |
| 规则近期表现 | 近20/60日胜率、近20/60日平均收益、近20日夏普 |
| 规则历史衰减特征 | 近20日触发频次、历史最大回撤、历史盈亏比 |
| 市场环境 | 大盘20日涨跌幅、大盘20日波动率、市场宽度(上涨比例) |
| 个股状态 | 个股20日涨跌幅、个股20日波动率、日均换手率分位 |
| 信号强度 | 因子实际值 vs 阈值的偏离程度 |
| 板块信号拥挤度 | 同行业当天触发规则总条数、同行业触发个股占比 |

### 5.2 模型配置

| 配置项 | 参数 |
|--------|------|
| 模型 | LightGBM Ranker |
| 目标函数 | lambdarank |
| Label | **滚动预测**：用t-1日数据预测t日超额收益（上下1%缩尾） |
| 排序分组 | 按「日期+行业」分组，仅同组内横向对比 |
| 输出 | MinMax 归一化至 0-100 |

> **关键修正**：采用滚动预测避免未来函数风险，严格时间序列分割

### 5.3 模型流程

```
每日 每只股票 触发规则列表
    │
    ▼
  特征构建 (含异常值1%缩尾处理)
    │
    ▼
  LightGBM Ranker (按日期+行业分组排序)
    │
    ▼
  每条信号置信度分数 (0-100)
    │
    ▼
  同一股票多条规则 → 加权融合 (权重=置信度)
    │
    ▼
  最终输出: 日频股票-买入评分矩阵 (新 FUSION_SCORE 0-50)
```

### 5.4 训练与更新

- **训练数据**：最近3年全市场信号，严格隔离训练/验证/测试时间
- **验证**：时间序列3折滚动交叉验证（TimeSeriesSplit）
- **重训频率**：每季度 + 策略库新增≥20条时即时增量重训
- **规则淘汰**：置信度均值<30（经回测验证的有效性阈值）、长期负收益规则 → 降级 → 连续2轮垫底则移出
- **故障恢复**：模型训练失败时自动回退到Phase 2原始评分

### 5.5 系统对接

- 手工5条基线策略与 Phase 1+2 进化规则同权参与训练和信号触发
- 最终输出替代现有 `FUSION_SCORE`，区间 0-50，与下游 `fuse_signals()` 兼容
- **下游适配**：SignalAgent需处理0-50范围，防止超限

## 六、Phase 4: 动态策略选择器

新增模块：`strategy/dynamic_selector.py`

### 6.1 核心机制：双滑动窗口回测选 Top-K

**执行时间：每周五 15:30**

```
策略库 (N条，N>100)
    │
    ▼
取双窗口信号: 60日 + 120日 (全市场采样200只，分层+行业中性)
    │
    ▼
独立回测，生成双窗口净值曲线
    │
    ▼
双窗口综合评分 (60日×0.6 + 120日×0.4)
    │
    ▼
关键约束过滤 → 排序 → 相关性去重
    │
    ▼
选 Top-K (K动态，3~7条) → 锁定整周实盘
```

### 6.2 滚动综合评分

```
单窗口评分 = 0.2×年化收益 + 0.25×胜率 + 0.3×夏普比率 - 0.2×最大回撤 + 0.05×卡玛比率
最终评分 = 60日评分×0.6 + 120日评分×0.4
```

### 6.3 关键约束

| 约束 | 规则 |
|------|------|
| 最少交易数 | 近60日交易<5 → 排除 |
| 最大回撤 | 近60日回撤>20% → 排除 |
| 收益下限 | 近60日收益<-5% → 排除 |
| 换手率 | 日均>1.2 淘汰，1.0~1.2 评分×0.7 |
| 最大连续亏损 | 近60日连续亏损>12天 → 排除 |
| 相关性去重 | **动态阈值**：牛市70%，熊市50%；且强制保留至少1条趋势/反转策略 |

### 6.4 Top-K 动态调整

| 通过约束数量 | K值 |
|-------------|------|
| 0 | K=0（触发 L1 保底） |
| 1-2 | K=通过数 |
| 3-7 | K=通过数 |
| ≥8 | K=7 |

### 6.5 个股信号融合

```
股票A当天触发活跃策略: [Rule_12, Rule_37, Rule_88]
    │
    ▼
取各规则 Phase 3 置信度 (0-100)
    │
    ▼
权重 = e^(置信度/30) / Σe^(置信度/30)
    │
    ▼
最终买入评分 = Σ(置信度 × 权重) → RiskAgent
```

### 6.6 三层保底机制

| 层级 | 触发条件 | 动作 |
|------|----------|------|
| L1 | 活跃策略=0 | 回退手工5条基线 |
| L2 | 连续3周活跃<3 **且非熊市** | 告警 + 强制触发 Phase 1+2 全量重刷<br>**熊市特殊处理**：启用熊市基线策略 |
| L3 | 连续4周仍 L2 | 紧急告警 + 临时放宽入库门槛(0.6→0.45, 4周后恢复) |

### 6.7 调度时序

| 频率 | 动作 |
|------|------|
| 每日 15:30 | 信号触发 + Phase 3 LightGBM 打分 |
| 每周五 15:30 | Phase 4 双窗口选 Top-K，锁定整周 |
| 应急 | 单日全市场回撤>3% → 临时重跑 Phase 4 |
| 每月末 | 复盘清理低分/失效规则 |
| 每季度 | Phase 3 全量重训 LightGBM |
| 按需 | 策略库新增≥20条 → Phase 3 增量重训 |
| 按需 | 连续3周 L2 → Phase 1+2 全量进化 |
