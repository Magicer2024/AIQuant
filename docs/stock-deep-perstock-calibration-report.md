# 个股深度「按本股标定」实验结论与后续优化方向

- 日期：2026-09-08
- 板块：个股深度（`strategy/stock_deep.py` + `routes/investor.py::stock_deep` + `dashboard.html` 深度面板）
- 状态：**结论已定，生产代码未改动**。两个实验脚本均为只读，不写库。
- 需求原话：「个股量化学习后掌握自己股票的涨跌规律，然后给出买点卖点规则」

---

## 0. 结论摘要

1. **入场侧已经饱和**。把分档阈值从"全市场绝对常量"换成"本股历史分数分位"，在等命中数下胜率没有正贡献（T+5 67.9% → 66.4%），平均收益持平。这条杠杆已经用尽，不要再动阈值。
2. **"全局尺子对不同性格的票不公平"这个动机是错的**。实测全局阈值跨股分布相当均衡（没有一只票从不产出信号，信号最多的前 10% 票只占 15.1% 买点），所以"按个股标定阈值"缺乏现实依据。
3. **真正没做的部分在出场侧**。当前 84.7% 的交易是被"持有满 10 天"这个时间常数了结的，**止盈价在 10 天内只有 4.7% 真的触达**，且触达率与本股波幅强相关（波幅最小的十分位 1.0% → 最大的十分位 8.6%）。用户看到的绿色止盈虚线，绝大多数情况下是一条到达不了的目标价。
4. 因此，最贴近原始需求（"掌握自己股票的规律 → 给出买卖规则"）且**有数据支撑**的下一步，是把**出场参数**（止盈可达性、止损宽度上限、持有期）按本股波段幅度标定，而不是继续调入场阈值。

---

## 1. 本次要回答的问题

需求定义拆开是两半：**学本股规律**（自适应）和 **给出买卖规则**（可执行）。

现状对照（改动前）：

| 环节 | 是否 per-stock | 实现 |
|---|---|---|
| 摆动切分阈值 | ✅ 是 | `max(2.5×该股ATR中位, 3%×价格中位)` |
| 节奏统计（腿长/波幅/周期/当前阶段） | ✅ 是 | `detect_rhythm` zigzag |
| 指标打分权重 | ❌ 全局常量 | `_signal_at`：±1/±2/±3 手写加减分 |
| 买卖档位阈值 | ❌ 全局常量 | `_classify`：≥5 buy / ≥2 add / ≥−2 hold |
| 入场/止损/止盈价 | ❌ 全局常量 | `stop=收盘−2.5×ATR`，`take=收盘+2.5×风险` |

所以本次只做一件事：**把档位阈值的来源从"全局常量"换成"本股分布"，其余全部不动**，看胜率和收益率有没有变化。

## 2. 实验一：分档阈值按本股分数分布分位标定

脚本：`tools/_eval_perstock_threshold.py`（只读，300 只 51 秒）

### 2.1 设计与公平性约束

| 约束 | 做法 | 为什么必须 |
|---|---|---|
| 单一变量 | 只换阈值来源，`_signal_at` / `_rhythm_adjust` / 指标全不动 | 否则无法归因 |
| 无未来函数 | 第 i 天的分位只用 `[暖机, i)` 的本股历史分数（expanding） | 否则胜率虚高 |
| 比较域限定 | 只比分位阈值已可用的日子（每股前 60 天没有本股历史） | 否则 baseline 含一批 treatment 结构上不可能命中的日子 |
| **等命中数对比** | 取"最接近 baseline 命中数"的分位档，并同时扫一遍全局阈值 k=2..7 作**对照臂** | 收紧阈值本身就会提高胜率，不对照就会把"变严"误读成"per-stock 有效" |

样本：300 只主板活跃非 ST（46,500 股·日）＋ 199 只 `deep_track` 已跟踪票（30,845 股·日，部署队列口径）。
收益口径：次日开盘买 → T+N 收盘卖，与 `tools/_eval_deep_buypoints.py` 一致。

### 2.2 结果：等密度下没有正贡献

300 只主板抽样：

| 口径 | 命中数(密度) | T+1 胜率/均值 | T+3 胜率/均值 | T+5 胜率/均值 |
|---|---|---|---|---|
| baseline `score≥2`（现行） | 9027 (19.4%) | 61.6% / +0.902% | 66.5% / +2.118% | 67.9% / +2.833% |
| V1 纯本股分位 q=0.85 | 9627 (20.7%) | 60.4% / +0.883% | 65.1% / +2.044% | **66.4% / +2.769%** |
| V2 分位 ∩ 绝对下限 q=0.92 | 5850 (12.6%) | 61.7% / +0.944% | 67.3% / +2.242% | 68.3% / +2.984% |
| **对照臂** 全局 `score≥3` | 5414 (11.6%) | 61.9% / +0.974% | 67.4% / +2.208% | 67.9% / +2.873% |
| **对照臂** 全局 `score≥4` | 2801 (6.0%) | 62.9% / +1.054% | 69.4% / +2.327% | 69.7% / +2.988% |

- V1（纯 per-stock）等密度下**胜率 −1.5pp**、收益 −0.06pp，方向是负的。
- V2（相对/绝对取严）相对"最近密度的全局 k"差 **≤0.5pp / ≤0.11pp**；部署队列（199 只）同样 **≤0.7pp / ≤0.06pp**。
- 信号在个股内与时间上都是聚集的，**有效样本远小于名义的几千笔**，这个量级属于噪声。

### 2.3 机制：信号互换分解（本次最有信息量的产出）

把等密度档下的日子按两臂的取舍拆成三组，各自看前向表现：

| 分组 | 笔数 | T+5 胜率 | T+5 均值 |
|---|---|---|---|
| 两臂都选中（共同核心） | 8270 | 68.3% | +2.916% |
| 仅 baseline 选中 → 分位想**剔除** | 757 | 62.6% | +1.932% |
| 仅分位选中 → 分位想**新增** | 1357 | **54.4%** | +1.876% |

部署队列同向且更极端：新增组 T+5 只有 **52.1% / +0.581%**。

结论：**"收紧的那一半是对的，放松的那一半亏得更多"**，而且放松放进来的笔数还比剔除的多（1357 vs 757），净效果被抹平。分位新增进来的那批，本质是低波动、常年低分票的"相对高分日"，接近抛硬币。

### 2.4 被否的前提与卖点侧

- **跨股公平性**：300 只票里 0 只从不产出 buy/add；每股中位 30 个信号日（均值 30.1，最小 7，最大 57）；信号最多的前 10% 票贡献 15.1% 买点（完全均匀为 10%）。→ "绝对尺子对低波动票不公平"不成立。
- **卖点侧同样否决**：全局 `score<−2` 之后 T+5 前向 −2.410%（最能躲跌），本股低分位档只有 −2.025% ~ −2.241%。

### 2.5 一个结构性原因（值得记住）

**分数是整数、跨度只有约 −8~+7**，本股分位常常正好落在 2 或 3 上，于是"按个股标定阈值"与"换个全局常量"在数学上高度重叠 —— 这条杠杆本身就没有多少信息量。要做真正的 per-stock 差异化，必须作用在**连续量**上（ATR、波幅、价格），而不是离散分数。

## 3. 实验二：计划价到底可不可达（为后续方向验前提）

脚本：`tools/_eval_deep_exit_reach.py`（只读，200 只 / 9303 笔）

出场口径**完全复用生产路径** `strategy/exit_advisor.py::evaluate_exit_by_prices`：次日开盘买入、A股 T+1、卖出判定用**当日收盘价**、优先级 收盘破止损 → 固定止盈 → 到期（`get_max_hold("short")` = 10 个交易日）。

### 3.1 结果

全部 buy/add 笔的出场原因：**到期 84.7%｜止损 5.8%｜持仓中 4.8%｜止盈 4.7%**。

按本股平均上涨波幅（`detect_rhythm.up_amp_avg`）分桶：

| 桶 | 笔数 | 止盈触达 | 到期 | 止盈需涨(均值) | 持有期实际完成度(中位) | 胜率 | 均值 |
|---|---|---|---|---|---|---|---|
| 小波幅 <17.6% | 3056 | **2.1%** | 86.5% | +17.4% | 27% | 68.7% | +2.42% |
| 中波幅 17.6~26.7% | 3011 | 4.5% | 85.0% | +23.3% | 29% | 68.3% | +3.35% |
| 大波幅 ≥26.7% | 3236 | **7.2%** | 82.8% | +31.2% | 33% | 71.5% | +6.52% |

波幅十等分从 1.0% 单调升到 8.6%（约 8.6 倍）。

止损宽度（相对入场价）：中位 8.7%，**38.6% 超过 10%，12.4% 超过 15%**。

### 3.2 判定

- 前提成立且比预想更强：**`rr_target=2.5` 定出的止盈价，对多数票是 10 天内到不了的目标**（要求涨幅 17%~31%，而典型交易只走完 27%~33% 的路程）。
- 需要诚实标注的推论：**这个板块的"卖点规则"事实上只有一个时间常数**。止盈/止损合计只约束了 10.5% 的交易，其余全是 10 天到期。
- 与既有反馈一致：把这样一条线画成"止盈价"虚线，会被当成可执行计划读（见用户纪律「展示层宁可空白，也不要给出策略没产出的数字」）。这里数字是策略"算出来"的，但**不是它"做得到"的**——同一种误读风险。

## 4. 后续优化方向

按证据强度排序。每条都写成可证伪的形式：单一变量、成功信号、失败信号。

### 方向 A（推荐先做）：出场侧 per-stock 标定 —— 三个依次递进的单变量实验

主题：入场已饱和，缺口在出场。A1 是最便宜的判别，能决定 A2/A3 值不值得做。

**A1｜持有期扫描**（先做这个）
- 假设：既然 84.7% 由到期了结，`max_hold_days` 才是这个板块真正的主参数。
- 单一变量：`max_hold_days ∈ {5, 10, 15, 20}`，其余全不动。
- 成功信号：某个 N 相对现行 10 天在胜率或均值上改善 ≥1pp / ≥0.2pp。
- 失败信号：N 在 5~20 之间结果平坦（差异 <0.5pp）→ 说明"持有 10 天"够用，A2 的动机大幅减弱。
- 附带必查：加计单边交易成本约 0.1~0.15%（现行结论未计成本，短持有期会被吃掉一块）。

**A2｜把止盈改成"本股可达"的目标**
- 假设：`take` 改按本股波段幅度（如 `0.5×up_amp_avg` 对应涨幅）定，而不是 `2.5×风险`，触达率应显著上升且不伤收益。
- 单一变量：只替换 `take_profit` 的算法，止损与持有期不动。
- 成功信号：止盈触达率 4.7% → ≥20%，**且**每笔均值不降。
- 失败信号：触达率上升但均值下降 → 说明"拿满 10 天"本来就是更好的出场，此时正确动作是**改 UI 语义**（把这条线从"止盈价"改标注为"目标参考价"，或按既有纪律直接不画），而不是改策略。
- 这是 A2 与 UI 的联动点，两种结果都有明确落点，不会白做。

**A3｜止损宽度上限**
- 假设：38.6% 的交易止损宽于 10%，对 1 万元本金（单笔约 3 千元）意味着单票最大亏损 300~450 元 = 总资金 3%~4.5%，超出可承受范围。
- 单一变量：给个股深度加 `stop_cap_pct`（`evaluate_exit_by_prices` 已支持这个参数，只是这条链没传）。
- 成功信号：组合最大回撤下降，且胜率/均值不显著恶化。
- 必须同时报告：被收窄止损扫出后 10 天内的反弹率，避免把止损扫在最低点。

### 方向 B：让 hold 档产生信息

- 依据：hold 档（−2≤score<2）占 **56.1%**，T+5 胜率 **45.2% / −0.149%** —— 与随机无异，却在面板上以"观望持有"的形式给出，对已持仓者等于一个"继续拿"的指令。
- 单一变量：**不改分数**，只在 hold 档内部引入一个次级判据（候选：节奏阶段 `position_hint`、20 日区间位置 `frac20`）。
- 成功信号：能把 hold 内部切成前向差异 ≥1pp 的两组 → 值得落地为"观望偏多/观望偏空"。
- 失败信号：切不出差异 → 文案应改为"无信号"，不给动作建议（符合"宁可空白"纪律）。

### 方向 C：入场侧提升只能靠新信息源

- 结论：分数的绝对水平单调有效（全局 ≥2/3/4/5 的 T+5 = 67.9/67.9/69.7/72.3% 胜率、+2.83/+2.87/+2.99/+3.59% 均值），但这是**选择效应**，收紧的代价是密度从 19.4% 崩到 1.9%；且在 `deep_track` 部署队列上 `≥5` 的均值（+2.16%）**低于** `≥2`（+2.24%）—— 已被候选排序挑过的票再收绝对阈值不划算。
- 推论：想在入场侧再进一步，只能引入现有指标之外的信息（题材/资金/板块相对强度），而不是重新组合已有的这几个分数。注意本仓板块与题材数据管线尚不完整，这条的前置成本最高。

### 方向 D：验证纪律（防止后续结论被推翻）

1. 一律**先确认主板口径**。1 万元本金只能交易主板（排除 30/68），任何胜率/收益数字都要标注是不是"仅主板"。
2. 报告改动时使用**等命中数对比 + 全局阈值对照臂**，否则会把"变严"误读成"改进"。
3. 参数类改动做 **walk-forward**：只用信号日之前的数据标定，前向窗口评估（本报告的实验一已按此实现，可直接复用其 expanding 框架）。
4. 改动落到生产后，`deep_track` 面板不会自动追平，必须按 runbook 重建。

## 7. 已知局限（不影响两臂对比，但影响绝对数字解读）

1. `detect_rhythm` 的摆动切分阈值用了**全历史中位数**，含轻微前视。baseline 与 treatment 同样本，A/B 结论不受影响，但绝对胜率会略偏乐观。
2. 止盈/止损按**收盘价**判定触达（生产口径如此），盘中插针能碰到但记录不到 → 真实盘中触达率高于 4.7%；不改变"绝大多数到不了"的量级判断。
3. 两个实验都是"每个信号独立成笔"，笔与笔在时间上重叠，**不等于可同时在场的资金组合**；1 万元本金实际只能同时持有 2~3 票。
4. **未计交易成本**（印花税 + 佣金单边约 0.1~0.15%），持有期越短影响越大 —— 方向 A1 必须把成本加进去再下结论。
5. 样本窗口 250 个交易日、截止 2026-09-08，未覆盖完整牛熊周期。
