## 1. 议题性质与先验（写死的第一段）
B 的实质不是成本优化，而是一个尚未检验的机制假设：**10 日的负收益在 20-40 日尺度上会不会反转**。
- 成本摊薄的正确算术（管理A 更正版）：0.8%/10 日=0.08%/日；/20=0.04%/日；/30=0.027%/日；/40=0.02%/日。年化费用拖累（满仓轮动）：10 日=25 次往返=20%/年；20 日=10%/年；30 日≈6.7%/年；40 日=6.25 次=5%/年。
- 已实测锚：10 日全池毛均值 **-1.842%/笔**（阶段 1 H12，n=4028）。H=20 要过每笔 +1.0% 门槛需累计**反转 +2.84pp**；若负漂移线性延伸，H=30/40 外推毛值约 -5.5%/-7.4%，缺口更大。**成本摊薄只能把日度门槛压到 0.02~0.04%/日，压不动这个 2.84pp 级的反转。**
- 本线成败几乎完全取决于"长周期均值回复是否存在"；若不存在，持有越久只会越负。此先验不许包装成"降门槛所以有机会"。
- 交付优先级：**衰减曲线（H=1/2/3/5/10/20/30/40 累计毛收益路径）是首要交付物**（描述性，不占 α、不作"通过/候选"推论）；B1 三格只回答"过没过线"。

## 3. 结局定义与出场可成交性
- 毛收益（判定唯一口径）：信号日收盘价 → 该 code 序列第 i+H 根 bar 收盘价，**含出场顺延**（下条）。close-to-close，与阶段 1 同一把尺。
- **净额公式（已写进扫描脚本头部注释）**：net = gross − 0.80，0.80 为**整笔一次扣**，绝不摊到每日；摊薄只出现在 D 曲线的日度门槛列与年化拖累列（纯描述）。三档 0.80/0.70/0.60 各报一列 net。
- 出场顺延（机械规则，非自由度）：出场日 untradeable_exit := suspended=1 ∨ limit_down_sealed=1 ∨ one_word_down=1 → 顺延下一根 bar；**顺延 >5 个交易日仍不可成交→丢弃并计数**；数据用尽未解决→丢弃并单独计数。判定只用顺延后口径；顺延笔数与两类丢弃数逐格披露；不设"不顺延"平行判定口径。
- **C1 出场 flag 缺失**：出场日 flag 行缺失按"可成交"处理，但**逐格报缺失数与缺失率，任一格缺失率 >1% 立即停手上报**，不做静默假设。
- 未成熟丢弃：i+H ≥ 序列长度 → 丢弃，**按月 × 按 H 分别报丢弃数**（实表替换附录 A 预计数进结案文档）。
- 信号窗与判定窗分开写：每格报信号窗 [S_start, 该 H 实际最晚成熟 scan_date]（数据推出的实值，只披露）与判定窗终点；不同 H 窗长不同是结构事实，靠丢弃表披露，不许在同一句里混比。

## 5. 判定格子清单、门槛与三态
### 双层门槛（必改 2，两列都报、任一不过即"不通过"）
- **基础门槛：毛 > 1.0%/笔**（覆盖 0.8% 成本 + 0.2 缓冲）。
- **稳健门槛：毛 > 1.63%/笔**——由 −30% 取整公式推出的有效字面线：nm=n+⌈n×0.02/0.98⌉≈1.0204n，sens=(毛×n−30×(nm−n))/nm，令 sens>1.0 得 毛>1.0204+0.6122≈1.6326 → 字面线 **1.63%**。逐格判定仍取**公式值 sens>1.0**（含取整的精确值），1.63% 为披露用有效线。此方向为保守，必须显式写明，防止将来"毛 1.2% 被判不过"被当成 bug。
### B1（判定格，m=3）

**子窗口稳健性口径替换声明（不是沿用）**：阶段 1 为"4 个不相交子窗口 ≥3/4 正"；本线因各 H 窗长不同、固定 4 段不可比，替换为**日历月口径**：非空月=该月格内 n≥20，要求非空月数 k≥3 且正值月数 ≥⌈0.75k⌉；结果表保留**逐月 n 与逐月毛值**两列；结案文档禁用"3/4 正"旧表述。

## 6. bootstrap / 功效 / 丢弃（公式）
