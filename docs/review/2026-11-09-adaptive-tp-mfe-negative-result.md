# 2026-11-09 负结果记录：A 方案「历史 MFE 分位锚定止盈」样本外判负

## 结论
**不上线。** 用个股过去 250 交易日「20 日前向收盘最大涨幅」分布的 P 分位替换深析链止盈距离
（`stock_deep._reachable_take` 的波幅标定），在样本外无任何可检测效应；六条验收门槛挂四条。
生产参数零改动。

## 实验设计
- 单变量：只改止盈距离来源；止损（sig_stop）、到期（max_hold=10）、建仓（回踩买点）全部不动。
- 样本：deep_track 已平仓 302 笔（2026-06-10 ~ 2026-11-05）；IS=6-8 月 182 笔选参，OOS=9-11 月 120 笔验证。
- 选参：P∈{55,60,70}，按 IS 净均值最大冻结 P*=70（IS：P55 -0.02% / P60 +0.13% / P70 +0.24%）。
- 复现器对账门：现行 sig_tp 重放 vs DB 结算收益 100% 一致（中位差 0.003pp），排除口径错。
- 成本：0.36% / 0.40% / 0.46% 三档敏感性（personal_config 直算 / 含最低佣金 / 含缓冲），
  diff 对成本平移不敏感，三档结论同向。

## 结构性解释（为何止盈端难有作为）
1. 69% 样本走到期、仅 11% 走止盈 → 止盈距离改动最多影响约 1/3 单子，效应天然被稀释 3 倍。
2. 基线收益主驱动是市场状态：逐月净均值 6月-4.90% / 7月+2.55% / 8月+1.27% / 9月-1.81% / 10月-1.18%，
   半年均值 0.00%（毛）是 regime 波动的假象中点。
3. **检出下限：±0.6pp/笔以内 |效应| 在 n=120 OOS 下不可检出**（半年样本、月度噪声 ±2-5pp）。
   要翻案须先把 walk-forward 扩到 2024-2026 全历史重放，前提是个股历史复权口径闭合
   （em/tx 兜底链存在 adjustflag=3 不复权路径，见 2026-11-09 群内派单）。
